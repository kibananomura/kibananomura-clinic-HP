# 院長ブログの予約公開（ストック）

ここに置いた原稿は、frontmatter の `date`（YYYY.MM.DD）の朝5時（日本時間）に、GitHub Actions（.github/workflows/publish-scheduled.yml）が自動で content/blog/ へ移して公開する。

- **公開の順番・日付は変わることがあります。** 変えるときは、原稿の `date` を書き換えるだけでよい。
- 公開を止めたいときは、`date` を先の日付にする（またはこのフォルダから出す）。
- 公開前の原稿は、関連する公開済み記事の末尾に「近日公開」としてタイトルだけ予告される（`related` でつないだ記事）。
- 似たテーマを続けないよう、シリーズもの（足・糖尿病・痛風）は数日あけて交互に並べている（ドラマの「次回へ続く」の間合い）。
